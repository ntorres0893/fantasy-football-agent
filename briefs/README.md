# Morning Briefs

Dated fantasy briefs, newest filename = latest. Each morning the 7 AM Routine
generates `YYYY-MM-DD.md` here and emails it to the manager.

The daily run reads the most recent brief before writing a new one, so each brief
reports **only what's new** — read top-to-bottom for the story of the season.

Generation is defined in `../agent/morning-brief-prompt.md`.
